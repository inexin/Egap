# Test fonts

Fonts the canvas text tests embed. Each is a cut of a font from Egami's test fonts, made with Egami's subsetter.

| File | What it is | Licence |
| --- | --- | --- |
| NotoSans-Latin.ttf | Noto Sans Regular (hinted TrueType) cut to U+0020–U+017E, no layout tables | SIL OFL 1.1 (Noto-OFL.txt) |
| NotoSansArabic-Regular.ttf | Noto Sans Arabic Regular, whole (kashida tests need its tatweel and joining forms), from Egami's shaping test fonts | SIL OFL 1.1 (Noto-OFL.txt) |
| SourceSans3-Latin.otf | Source Sans 3 Regular (OpenType CFF) cut to U+0020–U+017E, no layout tables | SIL OFL 1.1 (SourceSans3-OFL.md) |
| Twemoji-COLRv0-subset.ttf | Twemoji Mozilla 0.7.0 (COLR v0) cut to 25 emoji, as in Egami | CC-BY 4.0 graphics (Twemoji-CC-BY-4.0.txt, Twemoji-Mozilla-LICENSE.md) |
