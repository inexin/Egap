# Cases where Egap knowingly differs from Excel: the formula as in functions-regex.txt, a tab, and why.
REGEXTEST("((a))","\((?:[^()]|(?R))*\)")	Recursion, (?R), has no .NET form: Egap gives #VALUE! for the pattern.
REGEXTEST("ab","(?|(a)|(b))\1")	A branch reset group, (?|, has no .NET form: Egap gives #VALUE! for the pattern.
REGEXREPLACE("a"&CHAR(13)&CHAR(10)&"b","","-")	An empty match inside a CRLF: Excel skips the place after the LF, Egap does not.
