AreaBox

CellBorders

CellBox

A table cell, with its blocks, borders and shading.

DocumentLayout

A document laid out into pages (Phase 6 design Q11 and Q13): an immutable snapshot, each page a tree of boxes linked to the model nodes they show. An edit to the document needs a new layout.

FontSettings

Where the layout engine finds fonts (Phase 6 design Q12): the document's embedded fonts first, then the caller's collections, then the system's, then metric-compatible substitutes from Egap.Fonts, then a last resort. Every font the document names and the chain could not give as asked is reported as a FontSubstitution.

FontSubstitution

One font the layout could not use as the document asked, and what it used instead.

LayoutBox

One box of a laid-out page (Phase 6 design Q13): its place on the page, the model node it shows, and the boxes inside it. Boxes are immutable; a new layout makes new boxes.

LayoutDrawObserver

Told what Draw(Canvas, LayoutDrawObserver?) is drawing, so the target canvas can group its output: Egap.Pdf.Conversion marks each line and picture with its structure element and the rest as artifacts (Phase 6 Build Plan task 22). Every Begin is matched by its End, and calls nest as the boxes do.
