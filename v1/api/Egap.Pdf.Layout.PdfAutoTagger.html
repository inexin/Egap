Class PdfAutoTagger

Namespace
Egap.Pdf.Layout
Assembly
Egap.Pdf.Layout.dll

Tags an untagged PDF from its layout (design Q11, Build Plan task 14): a structure tree through Phase 5's model, with headings, paragraphs, lists, tables, figures, captions, quotes, code and notes in reading order, page headers and footers and decoration marked as artifacts, and the page content wrapped in marked content that points at its element. Figures get no alternate text: the report lists them, and writing it stays with the caller.

Examples

using PdfDocument pdf = PdfDocument.Open("report.pdf");
PdfAutoTagReport report = PdfAutoTagger.Tag(pdf);
foreach (PdfAutoTagFigure figure in report.FiguresWithoutAltText)
{
    Console.WriteLine($"page {figure.PageIndex + 1}: figure at {figure.Bounds} needs alternate text");
}

pdf.Save("report.pdf"); // an incremental update by default

Methods

Tag(PdfDocument, PdfLayoutOptions?, CancellationToken)

Tags document when it has no structure tree; a document that has one is left as it is. Save the document afterwards; by default that writes only the changes, as an incremental update.
