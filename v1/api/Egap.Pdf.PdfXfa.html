The XFA form of a document (12.7.8, hub Q7): the form's /XFA, one XDP stream or an array of named packets. Egap keeps it on save as it is, reads its packets, and keeps the datasets packet in step with the AcroForm field values: setting a field's value writes it into the data too. A static XFA form converts to a plain AcroForm with ConvertToAcroForm(); a dynamic one, which has no AcroForm fields of its own to fall back on, is reported by IsDynamic and not converted.

Remarks

A field maps to the data by its fully qualified name, as XFA forms name their AcroForm fields (form1[0].page1[0].name[0]): each part is an element of that name, the n-th of its siblings with that name, below xfa:data; unnamed subforms (#subform[0]) and the template's areas bind no data and are skipped. XML is read with DTDs prohibited and no external resolution.
