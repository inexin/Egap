Namespace
Egap.Pdf

Egap.Pdf.dll

What kind of repair a PdfWarning records.

public enum PdfWarningCode

Fields

AppearanceNotDrawn = 32

An appearance stream was not drawn, such as for text the standard 14 fonts cannot show; the annotation or field keeps the appearance it had.

BrokenXrefChain = 21

A /Prev or /XRefStm pointed nowhere useful or back into the chain; older sections were not read.

DamagedFilterData = 18

A stream's encoded data was damaged; what decoded before the damage was kept.

DuplicateKey = 12

A dictionary had the same key twice; the last value was kept.

FieldRenamed = 34

An imported form field was renamed with a suffix, since the document has a field of that name (Phase 2 Q5).

FontProgramUnreadable = 40

A font's embedded program could not be read as TrueType, OpenType, CFF or Type 1; the font's metrics and text still work, but not its outlines.

InvalidReference = 13

A reference had an object number below 1 or a generation above 65,535; it was read as null.

MalformedContent = 36

A content stream held something that is not an operation (stray delimiters, operands with no operator after them, an unclosed array, a stream that could not be decoded); it was skipped or closed and reading went on.

MalformedDictionary = 11

A dictionary key was not a name, or a key had no value; the entry was dropped.

MalformedEncryption = 28

Encrypted data or the encryption dictionary was malformed; it was read as far as it made sense.

MalformedFilterParameters = 19

A filter's /DecodeParms held values out of range; the filter ran with its defaults or without a predictor.

MalformedHexString = 5

A hex string held a character that is not a hex digit or white space, or had no closing >.

MalformedInlineImage = 38

An inline image's end (EI) could not be found where its length or filters put it; it was found by searching, or the image runs to the end of the content.

MalformedName = 3

A name had a # not followed by two hex digits; the # was kept as is.

MalformedNumber = 1

A number was malformed (such as --5, 1.2.3 or 4-2) and was read the way other readers do.

MalformedObjectStream = 22

An object stream's header or offsets were malformed; the objects that could be found were kept.

MalformedOutline = 31

The outline was malformed (chains of items that loop or reach something that is not an item, or a wrong /Parent, /Prev or /Last); it was repaired in memory.

MalformedPageTree = 30

The page tree was malformed (kids that are not dictionaries or loop back, a wrong /Type, /Parent or /Count, or no tree at all); it was repaired in memory.

MalformedStreamKeyword = 15

The stream keyword was not followed by a line feed or carriage return and line feed.

MalformedTree = 29

A name tree or number tree was malformed (its nodes loop, its limits or entries are missing, wrong or out of order); it was read as far as it made sense, and rebuilt from its entries when edited.

MalformedXref = 20

A cross-reference table or stream was malformed (wrong counts, bad entries, numbering off by one); it was read as far as it made sense.

MissingEndobj = 14

An indirect object had no endobj.

MissingEndstream = 17

A stream had no endstream; its data was taken to run to endobj or the end of the file.

MissingHeader = 24

The file has no %PDF-n.n header in its first kilobyte; version 1.7 was assumed.

MissingObject = 23

An object was not where the cross-reference said, or had another number or generation, or could not be loaded; the reference was read as null.

MissingSeparator = 7

Two tokens were run together with no white space or delimiter between them.

NotImported = 33

Part of a source document was not brought along with imported pages, such as its structure tree (tagged PDF comes in 5.x) or its XFA form.

NumberOutOfRange = 2

An integer was too large for 64 bits and was read as a real number.

ObjectRelocated = 27

An object was not at the offset the cross-reference gave; it was found nearby or by scanning the file.

PageReferencesRemoved = 35

A removed page's outline destinations, links or named destinations were cleaned up (Phase 2 Q7); the message gives the counts.

RasterFallback = 39

A PdfCanvas call that PDF cannot express (a blur, noise, a Porter-Duff blend, a layer filter) was drawn into an image at the fallback resolution and placed instead (Phase 3 design Q14).

ShiftedOffsets = 25

The header was not at the start of the file, and the file's offsets count from the header; they were read that way.

SignatureInvalidated = 42

A save or a new signature changes the document in a way an existing signature does not allow, or rewrites a signed file whole, so that signature no longer verifies (Phase 5 design Q7); in strict mode it throws instead, and AllowInvalidatingSignatures or AllowInvalidatingSignatures lets it go ahead.

TextWithoutUnicode = 41

Text extraction found glyphs whose fonts say no Unicode text for them (no ToUnicode map, no glyph name the Adobe Glyph List knows); they were given private-use characters (Phase 3 design Q10).

TooManyWarnings = 8

The file had so many warnings that the rest were dropped.

UnexpectedDelimiter = 6

A stray delimiter () or a single >) was skipped.

UnexpectedToken = 9

A token that cannot appear where it was found, such as an unknown keyword or a stray ], was skipped.

UnterminatedObject = 10

An array or dictionary was not closed; it was closed where the object ended.

UnterminatedString = 4

A literal string ran to the end of the data without its closing parenthesis.

WrongOperandCount = 37

An operator had more or fewer operands than the spec gives it; the operation was kept as written.

WrongStreamLength = 16

A stream's /Length was missing or wrong; its data was found by searching for endstream.

XrefRebuilt = 26

The cross-reference could not be used, or named no catalog; it was rebuilt by scanning the file for objects.
