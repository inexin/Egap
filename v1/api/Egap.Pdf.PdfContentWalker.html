Class PdfContentWalker

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

Walks content with its resources and tracks the graphics state (8.4) through it: the transformation matrix, q and Q, the text state and matrices, colours and colour spaces, clips, graphics state dictionaries and marked content. It descends into form XObjects and Type 3 glyph procedures. Derive from it and override the On methods to see paths, glyphs, images, shadings and marked content with the state they are drawn in (Phase 3 design Q3).

Remarks

The walk is as lenient as reading: an unknown operator is passed to OnOperation(PdfOperation) and otherwise ignored, an operator with missing or wrong operands is skipped, a Q without a q is ignored, and a resource that is not there is reported in Warnings. Form XObjects nest at most MaxNestingDepth deep, and a form that draws itself is not entered again.
