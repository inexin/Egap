OpenType features turned on or off for some text, such as liga=0 for no standard ligatures or tnum for tabular figures. A feature's value is 1 for on, 0 for off, or a number for features that choose among alternates. The set is compared by value, so two runs with the same features share formatting.

Parse(string)

A set from tags and values: the four-letter tag, then optionally = and a value ("liga=0, tnum"), or a leading + or - for on or off ("-liga, +onum"). Items are separated by commas or spaces; a later item for the same tag wins.
