The placeholders page furniture is written with, the same everywhere Egap fills text per page (stamps, and headers and footers on export): {page}, {total-pages} (also {pages}), {label} (the page label), {date}, {time}, {title} and {file}.

Examples

string footer = PdfPlaceholders.Fill("Page {page} of {total-pages}", new PdfPlaceholderValues { Page = 2, TotalPages = 9 });

Remarks

A number, date or time takes a .NET format after a colon: {page:000}, {date:yyyy-MM-dd}, {time:HH:mm}. Without one, {date} is the culture's short date and {time} its short time. A placeholder that is not one of these stays as written, and {{ writes a brace.
