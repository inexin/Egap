Parameters

The text: from the font's ToUnicode map, else its glyph name through the Adobe Glyph List, else a private-use character (U+E000 plus the code) that a warning counts.

Box PdfRectangle

The glyph's box (its advance by the font's ascent and descent), the smallest upright rectangle around it.

Font PdfFont

The font, or null when the content shows text with no font selected.

FontSize double

The font size in user space, the scale of the text matrix and the current transformation included.

Color PdfColor

The fill colour.

The character code shown, or -1 for an /ActualText span.
