Namespace

A document's named destinations (12.3.2.4), found through both lookups: the /Dests name tree in the catalog's /Names (PDF 1.2 and later) and the older /Dests dictionary in the catalog (PDF 1.1). A name in both is taken from the name tree. New names go in the name tree, which is edited in place (Phase 2 Q3).
