Class DocumentVisitor

Namespace
Egap.Documents
Assembly
Egap.Documents.dll

Walks a document tree through Accept(DocumentVisitor): a start and an end method for each node that holds others, one method for each inline. Override the ones you need; the rest continue. The walk does not recurse, so deeply nested tables cannot overflow the stack.
