Class PdfImpose

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

Imposition (Phase 7 design 7.2, Q9): new documents whose sheets draw the source's pages as form XObjects, placed and scaled. The source is never changed; it must stay open until the result is saved, which reads the pages' streams then. Every layout keeps each page's content, resources and printable annotations, shared once per source.
