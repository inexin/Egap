Class PdfConvert

Namespace
Egap.Pdf.Conversion

One-line conversions to PDF: HTML, Markdown, DOCX and images in, a PDF file or an open PdfDocument out. Each reads the input with Egap.Documents, lays it out and exports it as PdfExport does.

FromFile(string, PdfConvertOptions?)

Makes a PDF of a file: DOCX (and DOTX, DOCM), HTML and Markdown are laid out; an image file (JPEG, PNG, TIFF, WebP, GIF and the other formats Egami reads) becomes one page per frame. HTML and Markdown read their images from the file's own folder.
