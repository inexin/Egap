Layout as DoclingDocument JSON (design Q14, Build Plan task 18), the format Docling writes, schema version SchemaVersion: texts, tables, pictures and list groups in flat arrays, linked into reading order from the body by JSON pointers; roles as Docling's labels; bounds as provenance with the page number and a box from the page's bottom left, as PDF measures; page headers and footers in the furniture layer; and Egap's role and confidence in each item's meta. A DoclingDocument from Docling reads back into page layouts.

Read(string)

Reads DoclingDocument JSON (from Docling or from Write(IReadOnlyList<PdfPageLayout>, DoclingJsonOptions?)) into page layouts: texts become blocks with their roles, tables tables with their cells, pictures figures, in reading order. Blocks have one line per text, its words spread over the box, since the JSON keeps no line breaks or fonts.
