Layout analysis of PDF pages (design Q10, Build Plan task 10): blocks with roles, tables and figures in reading order, without building a document model. Tagged pages whose tags pass a sanity check are read from their tags (design Q2); others by geometric rules (design Q1, Q3 to Q7), every threshold an option and the main stages replaceable through PdfLayoutOptions.

foreach (PdfPageLayout page in PdfLayoutAnalyzer.Analyze(pdf))
{
    foreach (LayoutBlock block in page.Blocks)

    }
}

Analyze(PdfDocument, PdfLayoutOptions?, CancellationToken)

Analyses every page of a document. Roles that need the whole document come out right: headers and footers repeat across pages, heading levels rank across the document, and tables and paragraphs that run on to the next page say so.
