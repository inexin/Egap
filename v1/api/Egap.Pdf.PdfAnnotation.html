Class PdfAnnotation

Namespace
Egap.Pdf

Egap.Pdf.dll

An annotation (12.5): a thin view over its dictionary, typed by /Subtype through FromDictionary(PdfDictionary) (Phase 2 Q10). Subtypes Egap has no class for (Sound, Movie, Screen, 3D, RichMedia, PrinterMark, TrapNet, Watermark, Projection and any unknown one) are plain PdfAnnotations, read and written through Dictionary. Two views are equal when they wrap the same dictionary.

Remarks

A new annotation, made with a subtype's constructor, is stored once it is added to a page with Add<T>(T), and from then on reads the document and redraws its appearance when a property the appearance shows is set.
