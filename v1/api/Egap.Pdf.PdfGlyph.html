Parameters

Code int

The character code: one byte for simple fonts, one or more for composite fonts.

CodeLength int

How many bytes the code took.

Width double

The glyph's horizontal advance in thousandths of a text space unit (its width, before spacing).

Matrix PdfMatrix

The text rendering matrix at the glyph's origin: [size·scale 0 0 size 0 rise] × Tm × CTM.

IsWordSpace bool

Whether word spacing was added after the glyph: a single-byte code 32.
