Namespace Egap.Documents

Classes

Block

A node that goes into a story or a table cell: a paragraph or a table. Content controls and kept islands join in Build Plan task 5.

BlockContainer

A node that holds blocks: a story (body, header, footer) or a table cell.

BlockIsland

A block kept whole, such as an embedded document part (Word's altChunk), as raw markup.

Body

A section's main text.

Bookmark

A bookmark found in a document: its start, its end if any, and the text between.

BookmarkEnd

The end of a bookmark range.

BookmarkStart

The start of a bookmark: a named place, or a named range up to the BookmarkEnd of the same name.

Border

One border line: style, width and colour, the space between it and the text, and Word's shadow and frame flags.

Break

A line, page or column break inside a paragraph.

Cell

A table cell: blocks, nested tables included. Word wants at least one paragraph in every cell; the model allows none, and writers add the paragraph where the format needs it.

CellFormat

Table cell formatting: width, merges, vertical alignment, margins, borders and shading. Every property is nullable: null means not set here.

CharacterStyle

A character style: character formatting for runs.

Comment

A comment: its reference mark in the text, holding the comment's own text, author and date (Phase 6 design Q8). The text it is about lies between a CommentRangeStart and CommentRangeEnd with its Id. A reply names the comment it answers in ParentId, as Word does.

CommentRangeEnd

The end of the text a Comment is about; it pairs with the comment by CommentId.

CommentRangeStart

The start of the text a Comment is about; it pairs with the comment by CommentId.

CommentStory

The text of a comment.

CompositeInline

An inline that holds other inlines: a hyperlink or an inline content control.

ContentControl

A content control around blocks: paragraphs, tables and other controls.

ContentControlProperties

The settings content controls have, block or inline: kind, tag, title, locks and placeholder state.

ControlChar

The characters GetText() uses for what is not text, as Word's own text ranges do.

ConversionWarning

One kind of thing a writer left out, with how many times it happened.

Document

A flow document: a list of sections, each with its page setup, body and headers and footers, holding paragraphs, tables and the rest of the model (Phase 6 design Q3). The root of the tree; every other node belongs to exactly one document.

DocumentBuilder

Writes into a document at a cursor (Phase 6 design Q3, as Aspose.Words' DocumentBuilder): text, paragraphs, breaks, tables, pictures, fields, hyperlinks and bookmarks. The cursor sits in a paragraph, before an inline or at its end; Font and ParagraphFormat give what is written its direct formatting.

DocumentChangedEventArgs

One change to a document (Phase 6 design Q3, editor-ready model): the node, what happened to it and where. Code that keeps a view of the document, such as another library's editor or a cache, redraws from these; undo and redo can be built on them too.

DocumentException

A file could not be read as the format it was given as: not a package, a part missing or malformed beyond repair.

DocumentLimitException

A file went past one of the reader's limits (Phase 6 design Q9: part sizes, entry counts, compression ratio, nesting), so reading stopped instead of using unbounded memory or time. The limits are in the format's load options.

DocumentLimits

The limits a reader keeps to on untrusted files; the defaults suit any real document.

DocumentProperties

A document's properties: the core ones every format knows (title, author, dates) and custom ones by name, which fields such as TITLE, AUTHOR and DOCPROPERTY show.

DocumentSettings

Document-wide settings that change layout and numbering: the default tab stop, odd and even headers, footnote and endnote numbering, change tracking and Word's compatibility mode. Word's other settings are kept by the DOCX reader as extension data on the document.

DocumentVisitor

Walks a document tree through Accept(DocumentVisitor): a start and an end method for each node that holds others, one method for each inline. Override the ones you need; the rest continue. The walk does not recurse, so deeply nested tables cannot overflow the stack.

DocxFormat

Word's DOCX format, with its DOTX and DOCM variants (Phase 6 design Q9 and Q10): strict and transitional files read into the model, with what the model does not name kept as extension data so a DOCX round trip keeps it.

DocxLoadOptions

How DocxFormat reads a file.

DocxSaveOptions

How DocxFormat writes a file.

EmbeddedFont

A font file a document carries (Phase 6 design Q10 and Q12): the layout engine looks here first for a family's face.

ExtensionData

What a format's reader found on a node that the model does not name, kept so the same format's writer can put it back (Phase 6 design Q7): for DOCX, unknown elements and attributes as raw XML with their place among the mapped children. Each format keeps its own data under its name ("docx", "html"); writers of other formats leave it alone. An edit that removes a node removes its data with it.

Field

A field as a whole: its start, separator and end and the nodes between them. The code is the text between the start and the separator (or the end); the result is between the separator and the end. Fields nest, as in Word.

FieldEnd

The end of a field (Word's fldChar end).

FieldSeparator

The separator between a field's code and its result (Word's fldChar separate).

FieldStart

The start of a field (Word's fldChar begin). A field is a start, its code (runs), an optional separator, its result (runs, maybe over several paragraphs) and an end; GetField() gathers them.

FindOptions

How Find(string, FindOptions?) and Replace(string, string, FindOptions?) match.

FloatingPlacement

Where a floating picture, shape or text box sits and how text wraps around it (Word's anchor): position by alignment or offset from a reference area, wrap mode and side, the distances text keeps, and the stacking order. Immutable; set a new one to move the object.

FontFeatures

OpenType features turned on or off for some text, such as liga=0 for no standard ligatures or tnum for tabular figures. A feature's value is 1 for on, 0 for off, or a number for features that choose among alternates. The set is compared by value, so two runs with the same features share formatting.

Footnote

A footnote or endnote: the reference mark in the text, which holds the note's own text as a story (Phase 6 design Q8). The mark is numbered automatically unless it has a CustomMark.

FormatBase

A set of formatting properties as Word keeps them (Phase 6 design Q5): every property is nullable, and null means "not set here", so the value comes from the style, the document defaults or the application. The format of a node or style reports each change to its document; a format made with new stands alone, for passing to the methods that copy it.

FormatRevision

A tracked formatting change: who changed the formatting, when, and what it was before.

GroupPaging

How a group of blocks (a block content control) is placed across pages. Word keeps the blocks but not these settings, which only Egap's layout follows.

HeaderFooter

A section's header or footer of one HeaderFooterKind.

HeaderFooterCollection

A section's headers and footers: at most one of each kind.

HtmlFormat

HTML read into the model (Phase 6 Build Plan tasks 24 and 25): parsed as browsers parse it, styled through Egami.Css's cascade with HTML's default style sheet, and the computed styles mapped onto paragraphs, runs, lists and tables. Flexbox and grid are read as stacked blocks, with a warning (design Q15).

HtmlLoadOptions

How HTML is read (Phase 6 design Q14 to Q16).

HtmlSaveOptions

How the model is written as HTML (Phase 6 design Q16).

Hyperlink

A hyperlink: the inlines it holds link to an address, a bookmark in the document, or both.

ImageData

Image bytes as a file stores them, with their media type, such as image/png or image/x-emf.

Inline

A node that goes into a paragraph: a run of text, a tab or a break. Fields, hyperlinks, bookmarks, notes, comments and drawings join in Build Plan task 5.

InlineContentControl

A content control around inlines inside a paragraph.

Island

An inline kept whole (Phase 6 design Q4): a format's raw markup for an equation, chart, SmartArt diagram, OLE object and the like, with the picture the file stores for it, so it survives a round trip and draws as that picture.

List

A list paragraphs belong to (Word's num): a ListDefinition and, per level, an optional new start or level of its own. Paragraphs join it through SetList(List, int) or their style; ListLabel gives the computed label, such as "3.2.a".

ListCollection

A document's lists and list definitions (Phase 6 design Q6): Word's numbering part. AddBulleted() and AddNumbered() make a list with Word's default bulleted or numbered levels.

ListDefinition

A list definition (Word's abstractNum): nine levels with their numbering, labels and indents. Lists (List) use a definition; lists that share one continue each other's numbering unless one restarts.

ListLabel

A paragraph's computed list label.

ListLevel

One level of a list definition: where numbering starts, how numbers are written and the label's text, alignment and formatting, and the indents its paragraphs get (Phase 6 design Q6, Word's lvl).

ListLevelOverride

A change to one level of one list: a new start number, or a whole level of its own (Word's lvlOverride).

ListStyle

A list style (Word's numbering style): names the list its paragraphs and list definitions follow.

MailMergeOptions

How a mail merge fills a template.

MarginBox

Content in one of the page margins, drawn on every page of its section (or only on the first): text such as a title or "Page 3 of 9" with PAGE and NUMPAGES fields, as CSS's @page margin boxes hold. Headers and footers still apply; margin boxes sit beside them and do not move the body.

MarginBoxCollection

A section's margin boxes: at most one for each position, and one more for each on the first page.

MarkdownFormat

Reads Markdown into a Document and writes documents as GitHub Flavored Markdown (Phase 6 design Q17): CommonMark 0.31 with GitHub's tables, task lists, strikethrough, autolinks and footnotes, and YAML front matter. Headings take the Heading 1 to 6 styles, code the HTML Code and HTML Preformatted styles, lists Word list definitions built from their nesting. Writing says in warnings what Markdown cannot hold.

MarkdownImage

An image the Markdown writer hands to ImageResolver.

MarkdownLoadOptions

How MarkdownFormat reads Markdown.

MarkdownSaveOptions

How MarkdownFormat writes Markdown.

MergeData

Merge data from dictionaries, rows of values with column names, and objects.

Node

One node of a document tree: the document itself, a section, a story, a block such as a paragraph or table, or an inline such as a run of text. Every node belongs to one Document for its whole life and sits in at most one place in that document's tree; a node made for one document goes into another through Import(Node, bool).

NodeCollection<T>

The children of one kind a node holds, such as a story's blocks or a paragraph's inlines. The item type keeps wrong children out at compile time (a run cannot go into a story); adding also refuses a node of another document, a node already in the tree and a node that holds the parent.

NoteStory

The text of a footnote or endnote.

PageSetup

A section's page setup: paper size, orientation, margins, columns, page numbering and where it starts. Every property is nullable: null means not set here.

Paragraph

A paragraph: a list of inlines (runs of text, tabs, breaks and the rest) ended by a paragraph mark.

ParagraphFormat

Paragraph formatting: alignment, indents, spacing, keep rules, tabs, borders and shading (Word's paragraph properties). Every property is nullable: null means not set here.

ParagraphStyle

A paragraph style: paragraph formatting and the character formatting of its text.

Picture

A picture in the text: an image of given size, in the line or floating.

ResolvedParagraphFormat

A paragraph's effective formatting (GetEffectiveFormat()): every property with its final value, styles and defaults applied, tab stops added up. Where neither the document nor Word gives a value, Word's defaults apply.

ResolvedRunFormat

A run's effective formatting (GetEffectiveFormat()): every property with its final value, styles and defaults applied, theme fonts named. Where neither the document nor Word gives a value, Word's own defaults apply (10 pt, Times New Roman, automatic colour).

Revision

A tracked insertion, deletion or move on a node: what, who and when.

Row

A table row: its cells in order.

RowFormat

Table row formatting: height, header repeat and page splitting. Every property is nullable: null means not set here.

Run

A run of text with one formatting (Build Plan task 3).

RunFormat

Character formatting: font, size, colour, bold and the rest (Word's run properties). Every property is nullable: null means not set here.

Section

A part of a document with its own page setup (Build Plan task 3), a body and up to three headers and three footers (first page, odd or every page, even pages).

Shading

Shading behind text, a paragraph or a cell: a fill colour, a pattern and the pattern's colour.

Shape

A shape in the text, in the line or floating, with a fill and an outline, and optionally text inside it (a text box, Phase 6 design Q11).

Story

Content that flows on its own: a section's body or a header or footer. Footnotes, comments and text boxes join in Build Plan task 5.

Style

A named set of formatting that paragraphs, runs or tables point at, as in Word (Phase 6 design Q5). A style can be based on another of the same type, taking every property it does not set from it. Styles belong to one document's StyleCollection.

StyleCollection

A document's styles, by id, with the document defaults every style builds on (Word's docDefaults). A new document has Word's Normal paragraph style, Default Paragraph Font and Normal Table, with Word 2013+'s defaults (11 pt body font from the theme, 8 pt after paragraphs, 1.08 line spacing); AddBuiltIn(BuiltInStyle) adds the others Word knows, such as headings.

Tab

A tab: the text moves on to the paragraph's next tab stop.

TabStop

A tab stop: where, how text lines up, and the leader.

Table

A table: rows of cells, each cell holding blocks, so tables nest. Rows need not have the same number of cells; merged cells and widths come with the table format in Build Plan task 3.

TableFormat

Table formatting: width, alignment, layout, default cell margins, borders, shading and style options. Every property is nullable: null means not set here.

TableStyle

A table style: formatting for the whole table and, apart, for its first and last rows and columns, bands and corners.

TableStyleConditional

The formatting a table style gives one TableStyleRegion.

TextBoxStory

The text inside a text box.

TextColumn

One text column of a section with unequal columns: its width and the space after it, in points.

TextFormat

The document as plain text in reading order, for search and indexing (Phase 6 Build Plan task 8c): one line per paragraph, list labels before their text with a tab, table rows as tab-separated cells, text boxes after the paragraph they are anchored in, equations as their text. Field codes, deleted and hidden text, comments and pictures are left out.

TextMatch

A match Find(string, FindOptions?) found: where it is in its paragraph's text as Find sees it (runs joined, a tab as \t, a line break as \v, deleted text left out unless the options keep it) and the text it matched.

TextSaveOptions

How TextFormat writes plain text.

Theme

A document theme: twelve colours and the major (headings) and minor (body) fonts, which runs and styles name instead of fixed values, so changing the theme restyles the document. A new document has Word's Office theme (2013 to 2022).

ThemeColors

A theme's twelve colours.

TrackedChange

One tracked change in a document (Phase 6 design Q8): a Revision or FormatRevision on a node, which can be accepted or rejected on its own.

TrackedChangeCollection

A document's tracked changes in document order, to read, accept or reject.

DocumentColor

A colour as documents give it: automatic, a fixed colour, or a theme colour with Word's tint (towards white) or shade (towards black), so a theme change recolours the text that uses it. The default value is automatic.

TableWidth

A table or cell width: automatic, in points or in per cent.
