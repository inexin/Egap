Add(string, ReadOnlySpan<byte>, string?, string?, DateTimeOffset?)

Embeds a file under a name, replacing any attachment of that name. The embedded file stream records the size, MD5 checksum, MIME type and dates; the file specification gets the name as /F and /UF. In a PDF 2.0 document, or one that already lists associated files, the file is also added to the catalog's /AF.
