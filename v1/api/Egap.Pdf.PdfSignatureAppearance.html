Where and how a signature shows on a page (Phase 5 design Q6). Signatures are invisible unless given one: the Default(int, RectF, Raster?) layout shows the signer's name with the date, reason and location; Draw(int, RectF, Action<PdfCanvas>) lets the caller draw anything with the same PdfCanvas as pages. The appearance is part of the signed revision, so it is drawn before the file is hashed.

Default(int, RectF, Raster?)

The default layout: an optional image at the left, then the signer's name large, and under it the signing date, the reason and the location, in Liberation Sans (the bundled stand-in for Helvetica), inside a thin border.
