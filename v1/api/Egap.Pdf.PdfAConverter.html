Class PdfAConverter

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

Converts documents to PDF/A and checks them against the rules Egap enforces (Phase 5 design Q12, Q13). Conversion keeps the file's objects and fixes what it can, reporting every fix; if any rule cannot be met, nothing is changed. A converted document saves by the part's rules from then on: written whole, without encryption, as the part's version.

Examples

using PdfDocument pdf = PdfDocument.Open("report.pdf");
PdfAReport report = PdfAConverter.Convert(pdf, PdfAConformance.PdfA2u);
if (report.Succeeded)
{
    pdf.Save("archive.pdf");
}
else
{
    Console.WriteLine(report);
}

CheckUniversalAccessibility(PdfDocument)

Checks a document against the PDF/UA-1 basics Egap enforces for documents it creates (ISO 14289-1, design Q14): identification, title and language, every piece of content tagged or an artifact, figures described, annotations tagged, fonts embedded. Changes nothing; veraPDF's PDF/UA profile is the full judge.

Convert(PdfDocument, PdfAConformance, PdfAConvertOptions?)

Converts a document to conformance: adds the output intent and identification, removes encryption, scripts and forbidden actions, draws missing appearances, embeds fonts, re-encodes LZW and more, each fix a report entry. When a rule cannot be met the document is left unchanged and the report says why.
