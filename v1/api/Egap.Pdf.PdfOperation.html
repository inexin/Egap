One operation of a content stream (8.2): an operator and its operands, such as 1 0 0 1 72 720 cm. Operations are values: they are never changed after they are made, so an edited content stream replaces operations instead of changing them, and the operand objects (arrays and dictionaries included) should be treated as read-only.

Remarks

Operators the spec does not define are kept as they are, so content round-trips whatever it holds (Phase 3 design Q3). Operands are PDF objects: numbers, names, strings, booleans, null, and arrays and dictionaries of those.
