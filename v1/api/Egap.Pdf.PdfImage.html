An image a page draws (8.9): an image XObject or an inline image (Phase 3 design Q11). It gives the image's stored bytes and filters, so a JPEG can be saved as it is, and decodes to an Egami raster with its colour space, decode array and masks applied.

Replace(Raster, PdfImageEncoding?)

Replaces the image with a raster, in place (Phase 3 design, image replacement): the XObject keeps its object number, so every page that draws it shows the new image, and an incremental save writes only the new stream (and its soft mask). The raster's alpha becomes a soft mask; its RGB or gray ICC profile is kept. Width, height, colour space, filters and masks are rewritten; other entries (such as /Interpolate or optional content) stay.

public void Replace(Raster image, PdfImageEncoding? encoding = null)
