A stamp: text, an image or another page drawn on every page (or the pages chosen) as removable page furniture (Phase 7 design 7.3, Q10 and Q11). Make one with Text(string), Watermark(string), Bates(PdfBatesSequence), Image(Raster, double, double) or Page(PdfPage), then set its placement with with.

Remarks

Text is a template whose placeholders are filled per page, as PdfPlaceholders lists them: {page}, {total-pages} (or {pages}), {label} (the page label), {date}, {time}, {title}, {file} and, for a Bates stamp, {bates}. Numbers, dates and times take a format after a colon ({date:yyyy-MM-dd}) and use Culture, the invariant culture unless given. Text is drawn in Helvetica, a standard font that is not embedded, unless Font names a typeface, which is embedded as a subset; a PDF/A document needs one.
