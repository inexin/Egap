Class PdfOutlineItem

Namespace
Egap.Pdf

Egap.Pdf.dll

An outline item (12.3.3): a thin view over its dictionary, equal to another view of the same dictionary. It goes to a destination (/Dest) or runs an action (/A), and has a title, colour, style and open state.
