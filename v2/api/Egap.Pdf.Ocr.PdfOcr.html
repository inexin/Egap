Class PdfOcr

Namespace

Makes scanned PDFs searchable through any OCR engine (an Egami.Ocr.IOcrEngine from Egami.Ocr): each page's image goes to the engine, and the words that come back are written over the page as invisible text, placed and scaled so selection follows the scan. Egap ships no engine; plug in Egami.Ocr.CommandOcrEngine for a program such as Tesseract, or your own class around an OS or cloud service.

Examples

using PdfDocument pdf = PdfDocument.Open("scan.pdf");
CommandOcrEngine tesseract = new("tesseract {image} {output} -l {langs} --dpi {dpi} hocr", new CommandOcrOptions { Output = OcrOutputFormat.Hocr });
PdfOcrReport report = await PdfOcr.MakeSearchableAsync(pdf, tesseract, new PdfOcrOptions { PdfA = PdfAConformance.PdfA2b });
pdf.Save("searchable.pdf");

Remarks

The document is changed in place and saved by the caller. A page that is one scanned image is read as its own pixels; other pages are rendered. Pages go to the engine several at a time when it is thread-safe. A signed document is refused unless AllowInvalidatingSignatures.
