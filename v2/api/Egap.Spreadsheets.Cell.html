Class Cell

Namespace
Egap.Spreadsheets

A cell of a sheet: a small handle that reads and writes the sheet's store, made by sheet["B4"] or sheet.Cells[row, column]. The sheet keeps no handles; a cell with no value and the default style takes no room. Two handles for the same cell are equal. For bulk work, GetValue(int, int) and SetValue(int, int, CellValue) read and write values without a handle.

Formula

The cell's formula in Excel's stored form, English function names and commas, without the leading =; null when the cell holds none. A leading = given is dropped. Setting a formula keeps the cell's style; its result is empty until the workbook is calculated. Setting null or an empty string removes the formula and its result. A cell that shares the formula of another cell (a shared formula in an XLSX file) gives null here but has HasFormula set; its formula and result are kept and saved.
