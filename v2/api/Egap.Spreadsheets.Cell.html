A cell of a sheet: a small handle that reads and writes the sheet's store, made by sheet["B4"] or sheet.Cells[row, column]. The sheet keeps no handles; a cell with no value and the default style takes no room. Two handles for the same cell are equal. For bulk work, GetValue(int, int) and SetValue(int, int, CellValue) read and write values without a handle.

Formula

The cell's formula in Excel's stored form, English function names and commas, without the leading =; null when the cell holds none. A leading = given is dropped. Setting a formula keeps the cell's style; its result is empty until the workbook is calculated (see Calculate()). Setting null or an empty string removes the formula and its result. A cell that shares the formula of another cell (a shared formula in an XLSX file) gives that formula with its relative references moved to this cell, as Excel shows it; changing the first cell of a shared formula leaves the others their formulas. A formula set here means what it means typed in Excel: one that can give more than one value spills (see SpillRange), and @ asks for the old implicit intersection.

ImportData<T>(IEnumerable<T>, DataImportOptions?)

Writes a list of objects into the cells from this one down and to the right: a header row of property names, then one row per item with one column per public property, in declaration order. A list of plain values, such as numbers or strings, fills one column named Value.

public CellRange ImportData<T>(IEnumerable<T> items, DataImportOptions? options = null)

Parameters

items IEnumerable<T>
options DataImportOptions

Returns

CellRange

The cells written, header included.

Type Parameters

T

Examples

CellRange written = sheet["A1"].ImportData(orders, new DataImportOptions { TableName = "Orders" });

Remarks

Numbers become numbers, bool becomes TRUE or FALSE, and strings, characters, enums and GUIDs become text. DateTime, DateOnly and DateTimeOffset (its clock time) become date serial numbers with DateFormat or DateTimeFormat, and TimeSpan and TimeOnly fractions of a day with TimeFormat. Null leaves the cell empty; NaN and infinity become #NUM!. A date before the date system's first day becomes ISO text.

Exceptions

ArgumentNullException

items is null.

ArgumentException

A column in Columns does not exist, the type has no columns, or they run past the sheet's edge.
