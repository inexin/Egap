Class PageBand

Namespace
Egap.Documents.Pdf
Assembly
Egap.Documents.dll

A header or footer that PdfConvert puts on every page (Header and Footer), in the top or bottom margin: plain text in up to three places (Text(string?, string?, string?)), or HTML styled with the page's own CSS (Html(string)). Both take the PdfPlaceholders: {page}, {total-pages}, {label}, {date}, {time}, {title} and {file}.

Methods

Html(string)

A band of HTML across the margin. When the document was HTML, the band is styled with the document's own style sheets; images and links are read as the document's are. Applying it needs the Egap.Documents.Html package and HtmlFormat.Register(); without them the conversion throws a NotSupportedException that names them.
