Class FramePosition

Namespace
Egap.Documents
Assembly
Egap.Documents.dll

An old-style text frame (Word's w:framePr): the paragraph, with the paragraphs after it that have the same frame, is placed as a float by its anchors and alignment, and is never split across pages. A frame with a DropCap is a drop cap: its text sits at the start of the next paragraph, which wraps beside it. Immutable.
