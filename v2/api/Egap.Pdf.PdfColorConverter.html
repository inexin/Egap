Class PdfColorConverter

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

Converts a document's colours into a print profile (Phase 8 design Q6 to Q8): RGB, calibrated, Lab and ICC-based colours go to the target, CMYK and spot colours stay unless the options say otherwise, and vectors stay vectors. Colour operators, images, shadings, patterns, soft masks, Type 3 glyphs, annotation appearances and spot alternates are all converted. Ink coverage is not limited: the target profile sets it, and preflight reports anything over a print profile's limit.
