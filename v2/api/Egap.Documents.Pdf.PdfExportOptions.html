EmbedSource

Whether a DOCX of the document is embedded as the PDF's source (an associated file at the catalog's /AF with AFRelationship /Source), making a hybrid PDF that PdfToDocument opens again as the document instead of analysing its pages. Off by default. PDF/A-1 and PDF/A-2 do not allow it: the export throws an ArgumentException with them; PDF/A-3, PDF/A-4f and no PDF/A do.

FormFields

Whether form controls become PDF form fields at their laid-out place: HTML inputs, check boxes, radio buttons, selects and text areas, and DOCX plain text, date, drop-down list, combo box and check box content controls. Each field is named by the control's tag (an HTML name) and starts with its value; the control's own text is taken out of the page. Off by default.
