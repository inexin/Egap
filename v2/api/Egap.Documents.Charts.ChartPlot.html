Class ChartPlot

Namespace
Egap.Documents.Charts
Assembly
Egap.Documents.dll

One group of series drawn the same way against the same axes. A plain chart has one plot; a combination chart has more. Properties a type does not use read as null. On a cx: chart only the series, axes and gap width apply; setting the rest does nothing.
