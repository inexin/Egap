Enum LayoutAlignment

Namespace
Egap.Documents
Assembly
Egap.Documents.dll

How boxes line up along a container's axis: flex and grid containers and their items use the same values. Each property says which values it takes, as CSS gives each its own set; a value a property does not take lines up as Start.

public enum LayoutAlignment

Fields

Baseline = 7

CSS baseline alignment, read from HTML and written back; layout lines it up as Start.

Center = 2

Centred.

End = 1

At the end (right, or bottom).

SpaceAround = 5

The space shared around the boxes, half as much at the ends as between them.

SpaceBetween = 4

The space shared between the boxes, none before the first or after the last.

SpaceEvenly = 6

The space shared equally before, between and after the boxes.

Start = 0

At the start (left, or top).

Stretch = 3

Stretched to fill the space; for content, the space is shared among the tracks or lines.
