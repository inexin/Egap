Class EpubFormat

Namespace
Egap.Documents
Assembly
Egap.Documents.Html.dll

EPUB books read into the model and written from it: EPUB 2.0.1 and 3.0 to 3.3 read as one document with a section per chapter, the table of contents as outline levels and the metadata as document properties; the model written as an EPUB 3.3 book with a navigation document, an EPUB 2 table of contents for older readers, and accessibility metadata. Books under DRM are refused.
