Class TextStyle

Namespace
Egap.Documents.Reports

How text in a report looks: font, size, weight, slant, lines, colours, letter spacing and line height. Immutable: each method returns a changed copy, so a style can be kept and shared (TextStyle.Default.FontSize(18).Bold()). What a style leaves unset comes from the style of the text around it.
