Name

The sheet's name on its tab: 1 to 31 characters, none of : \ / ? * [ ], no apostrophe at either end, and unique in the workbook, case ignored. Setting it renames the sheet as Excel does: the formulas, names, rules, links and charts of the workbook that refer to the sheet follow, while text such as INDIRECT("Sheet1!A1") stays. A sheet Egap keeps unread and a pivot cache keep the old name.

DeleteColumns(int, int)

Takes columns out, as DeleteRows(int, int) does rows. A table loses its columns among them, and a structured reference to one of those becomes #REF!.

public void DeleteColumns(int column, int count = 1)

Parameters

column int

The zero-based first column to take out.

count int

How many columns to take out.

Remarks

Sheet protection does not block the edit: it guards what a person does in Excel, not what code does, as for writing cells.

Exceptions

ArgumentOutOfRangeException

The column is off the sheet, or the count is below 1 or runs past the sheet's end.

InvalidOperationException

The columns would take part of an array formula, or a pivot table would move or change.

Replaces matching text in the sheet's formulas and values, as Excel's Replace All does, and gives how many cells changed. See Replace(string, string, FindOptions?).

public int Replace(string what, string replacement, FindOptions? options = null)

Parameters

what string

The text to find.

replacement string

The text to put in its place, taken as it is.

options FindOptions

How to match; null for Excel's defaults. Only Formulas can be replaced.

Returns

int

How many cells changed.

Examples

int changed = sheet.Replace("Sheet1!", "Data!");

Exceptions

ArgumentException

The text is null or empty, the replacement is null, or the options look in values or notes.

InvalidOperationException

A replacement makes a formula Excel's grammar refuses; the cells before it stay replaced, as in Excel.
