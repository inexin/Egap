The sections a presentation's slides are grouped in, as PowerPoint's slide sorter shows them ([MS-PPTX] 2.3.3.25, p14:sectionLst). Sections split the slides in the order shown: each holds a run of them, and every slide is in one when there are any. Empty when the presentation has none.
