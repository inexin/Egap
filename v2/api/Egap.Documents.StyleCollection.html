A document's styles, by id, with the document defaults every style builds on (Word's docDefaults). A new document has Word's Normal paragraph style, Default Paragraph Font and Normal Table, with Word 2013+'s defaults (11 pt body font from the theme, 8 pt after paragraphs, 1.08 line spacing); AddBuiltIn(BuiltInStyle) adds the others Word knows, such as headings.
