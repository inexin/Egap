The document's editing restriction: what may change and the hash of the password that lifts it. Egap does not enforce the restriction; it reads, writes and keeps it through conversion, so that Word and other editors enforce it, and Verify(string?) checks a password against the hash.

Remarks

The hash is Word's: the password is first turned into Word's legacy 32-bit key, then hashed with the salt and hashed again SpinCount times ([MS-OFFCRYPTO] 2.3.7.1 to 2.3.7.4, ECMA-376 Part 1, 17.15.1.29).
