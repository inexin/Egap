Class PdfOutlineNode

Namespace

A node of the document outline (12.3.3): the outline itself or one of its items. Children are read through /First and /Next; adding, removing and moving keep /First, /Last, /Prev, /Next, /Parent and the /Count of every node above in step, touching only the nodes involved.
