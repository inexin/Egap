Preflight for print: lists what a document uses and checks it against a PdfPrintProfile. The report shows every output intent, colour space (with its ICC profile and spot names), image resolution, font, transparency, overprint and hairline, page by page, so a file can be shown to hold CMYK under a FOGRA39 intent, or found to carry an RGB photo. Preflight changes nothing.

Examples

using PdfDocument pdf = PdfDocument.Open("print.pdf");
PdfPreflightReport report = PdfPreflight.Run(pdf, PdfPrintProfile.SheetfedCoated);
foreach (PdfPreflightItem item in report.Items)
{
    Console.WriteLine(item);
}

foreach (PdfAIssue issue in report.Issues)
{
    Console.WriteLine($"{issue.Clause}: {issue.Description} (page {issue.Page})");
}
