Class PdfPreparedSignature

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

A signature waiting for its CMS (Phase 5 design Q3): the file is written with the space reserved, and Digest is what a signing service signs. CompleteAsync(ReadOnlyMemory<byte>, CancellationToken) writes the CMS it returns into that space, in the same stream; a file prepared earlier, in another process, is completed with CompleteAsync(Stream, ReadOnlyMemory<byte>, PdfTimestampClient?, CancellationToken).
