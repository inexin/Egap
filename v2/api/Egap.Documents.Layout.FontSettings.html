Class FontSettings

Namespace
Egap.Documents.Layout
Assembly
Egap.Documents.dll

Where the layout engine finds fonts (Phase 6 design Q12): the document's embedded fonts first, then the caller's collections, then the system's, then metric-compatible substitutes from Egami.Fonts.Substitutes, then a last resort. Every font the document names and the chain could not give as asked is reported as a FontSubstitution.
