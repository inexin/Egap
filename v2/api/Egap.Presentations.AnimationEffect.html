Parameters

ShapeId uint?

The id of the shape it animates (p:spTgt/@spid), or null when it animates none (a sound, say).

PresetClass AnimationClass

The kind of effect (presetClass).

PresetId int

PowerPoint's number for the effect within its kind (presetID): 10 is Fade, 2 Fly In, and so on.

PresetSubtype int

The effect's variant (presetSubtype), such as the direction a Fly In comes from.

Trigger AnimationTrigger

What starts it (nodeType).

DelayMilliseconds int

How long after its trigger it starts, in milliseconds; 0 when the file gives none.

DurationMilliseconds int?

How long it lasts, in milliseconds: its longest behaviour; null when it repeats without end or gives none.

TriggerShapeId uint?

For an effect a click on a shape starts, that shape's id; otherwise null.
