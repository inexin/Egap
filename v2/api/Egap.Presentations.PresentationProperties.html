Class PresentationProperties

Namespace
Egap.Presentations
Assembly
Egap.Presentations.dll

A presentation's properties: the core ones every Office file has (title, author, dates; docProps/core.xml), two of the application's (docProps/app.xml), and custom ones by name (docProps/custom.xml). They are read from the file each time and written into it when set, so everything else in those parts stays as it was. The names follow DocumentProperties.
