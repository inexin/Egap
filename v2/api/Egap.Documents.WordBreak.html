Where lines may break inside words.

public enum WordBreak

Fields

Anywhere = 3

A word too long for the line breaks where it must, others as normal (CSS overflow-wrap: anywhere).

BreakAll = 1

Between any two characters, so a long word, number or address never runs past the line (CSS word-break: break-all).

KeepAll = 2

Not inside words, also in Chinese, Japanese and Korean text (CSS word-break: keep-all).

Normal = 0

Only where the language's line breaking rules allow, as text usually breaks.
