Class PdfOcrLayer

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

An invisible text layer over a scanned page (Phase 5 design Q16): the words OCR found, drawn in render mode 3 (neither filled nor stroked) in a glyphless font Egap builds, each word scaled to its box, so the page can be searched, selected and read aloud while it looks exactly as the scan. Words come from hOCR (Tesseract, Kraken, OCRmyPDF) or ALTO (ABBYY, libraries' digitisation) files, or from any OCR engine as word boxes. The page image is not touched.

AddResult(PdfPage, OcrResult, PdfMatrix, double)

Adds an OCR engine's words as invisible text over the page's content. Each word's quad is mapped from the image's pixels to the page's user space by imageToPage; a rotated or skewed word gets a text matrix along its own baseline and is scaled across its width, so selection follows the scan. Words less sure than minConfidence are left out; a word's language goes on a /Span with /Lang when the document is tagged. Returns how many words were added.
