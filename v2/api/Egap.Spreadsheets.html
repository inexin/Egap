Namespace Egap.Spreadsheets

Classes

CalculationResult

What a calculation of a workbook did: how many formulas it calculated and which circular references it met.

CalculationSettings

How a workbook calculates: when, whether circular references iterate, and whether chains of formulas may be calculated in parallel. These are the workbook's own settings, saved with it (the calcPr element, ECMA-376 Part 1, 18.2.2).

Cell

A cell of a sheet: a small handle that reads and writes the sheet's store, made by sheet["B4"] or sheet.Cells[row, column]. The sheet keeps no handles; a cell with no value and the default style takes no room. Two handles for the same cell are equal. For bulk work, GetValue(int, int) and SetValue(int, int, CellValue) read and write values without a handle.

CellAlignment

The alignment, wrapping, indent and rotation of a cell's text.

CellBorders

A cell's borders: four edges and the diagonals.

CellComment

A note on a cell (Excel's classic comment): its author and text.

CellCommentCollection

A sheet's notes, at most one a cell.

CellFill

The fill behind a cell: a pattern in a foreground colour over a background colour.

CellFont

A cell's font.

CellProtection

What sheet protection does to a cell.

CellStyle

How a cell looks: its font, fill, borders, alignment, protection and number format. A style is an immutable value; change one with with, as in cell.Style = cell.Style with { Font = cell.Style.Font with { Bold = true } }, or for many cells at once with UpdateStyle(Func<CellStyle, CellStyle>). A workbook keeps each distinct style once, as Excel's cell formats table does, however many cells use it.

ChartSheet

A sheet that holds one chart and no cells. Its chart can be read and edited; the sheet itself is kept as the file had it.

ConditionalFormat

Conditional formatting on one or more ranges: the rules that apply to them.

ConditionalFormatCollection

A sheet's conditional formatting.

ConditionalFormatRule

One conditional formatting rule: its kind, formulas and the style it applies. Rules made in Excel that the model does not describe in full, such as an icon set's thresholds, keep those parts and write them back.

CsvOptions

How LoadCsv(string, CsvOptions?) reads and SaveCsv(string, CsvOptions?) writes comma- and tab-separated text (RFC 4180): the separator, encoding, culture and type detection.

DataValidation

A data validation rule: what its cells allow, the drop-down list and the messages Excel shows. Formulas are written without the leading =, in English, as in a cell's formula.

DataValidationCollection

A sheet's data validation rules.

DefinedName

A defined name: a name for a cell, a range, a constant or a formula, such as TaxRate for Sheet1!$B$1. A name belongs to the workbook, or to one sheet when it is local to that sheet. Excel's own names start with _xlnm., such as _xlnm.Print_Area.

DefinedNameCollection

A workbook's defined names. A name is unique among the workbook's names, or among one sheet's, case ignored.

FormulaException

A formula that does not follow Excel's grammar, with where in its text the problem is.

FunctionArgument

An argument given to a function added with Add(string, int, int, Func<IReadOnlyList<FunctionArgument>, CellValue>).

FunctionRegistry

The worksheet functions formulas can call: the built-in ones, and functions you add for your own formulas, as a user-defined function in Excel. A function you add is known to every workbook in the process from then on; formulas read it when they are next calculated or evaluated. It also answers a call written through an add-in's link, [1]!DOUBLE(21), which otherwise gives #NAME?: a workbook keeps no code for an add-in's functions.

Hyperlink

A hyperlink on a cell or range: to a web address or file (Address), or to a place in the workbook such as Sheet2!A1 or a defined name (Location). The cell keeps its own value; Excel shows it as the link's text.

HyperlinkCollection

A sheet's hyperlinks, in the order the file or code gave them.

MergedCellCollection

A sheet's merged cells: ranges shown as one cell, with the value and style of their top-left cell. Merged ranges do not overlap.

NumberFormatCode

An Excel number format code, parsed: up to four sections (positive, negative, zero, text) with colours, conditions, digit placeholders, thousands separators and scaling, percent, scientific notation, fractions, dates and times, elapsed times, text and literal characters, and locale tags such as [$-414]. Format(CellValue, CultureInfo?, bool) shows a value as Excel shows it in a cell, for a given culture; Text uses it.

PageBreakCollection

A sheet's manual page breaks in one direction, in order: each is the index of the row or column that starts a new page.

PageSetup

How a sheet prints: paper, orientation, scaling, margins, centring, gridlines, headings, page order, the header and footer, the print area, the rows and columns repeated on each page and the manual page breaks. The print area and the titles are kept as Excel keeps them, as the sheet's defined names _xlnm.Print_Area and _xlnm.Print_Titles in Names.

SheetColumn

One column of a sheet: its width, whether it is hidden, its outline level and the style of its empty cells.

SheetColumnCollection

A sheet's columns by zero-based index, and, when enumerated, the columns that have a width, are hidden, outlined or styled.

SheetDrawing

A picture, shape, chart or other object on a sheet's drawing layer. Its place and size and its name and alternative text can be changed, a picture's image replaced and a chart edited; everything else about it is kept as the file had it.

SheetDrawingCollection

A sheet's drawing objects, back to front.

SheetPage

A printed page of a sheet: its size, the cells on it, and drawing it.

SheetPdfOptions

How sheets export to PDF.

SheetPrintLayout

One or more sheets laid out on pages as Excel prints them (Build Plan task 17): the print area, the scale or fit to pages, the page breaks, the repeated titles and the page order give the pages; each draws on any Egami canvas.

SheetPrintOptions

How sheets lay out on pages to print, export to PDF or render as images.

SheetReader

Reads a sheet's rows one at a time from an XLSX file or CSV text, without building a Workbook: memory stays the same however many rows there are. An XLSX file's shared strings and styles are read first, as every cell may use them; the rows are then read from the sheet's part as they come.

SheetRow

One row of a sheet: its height, whether it is hidden, its outline level and the style of its empty cells.

SheetRowCollection

A sheet's rows by zero-based index, and, when enumerated, the rows that have a height, are hidden, outlined or styled.

SheetTable

An Excel table: a named range with a header row, optional totals row, filter buttons and a table style. Formulas can refer to it by name, as in SUM(Sales[Amount]).

SheetTableCollection

A sheet's tables.

SheetTableColumn

A column of a SheetTable: its name, which the header cell shows, and its totals.

SheetView

How a sheet shows on screen: gridlines, headings, zoom, direction, frozen panes and whether its tab is selected.

SheetWriter

Writes rows one at a time to an XLSX file or CSV text, without building a Workbook: memory stays the same however many rows there are. Each row goes straight to the file; the workbook's own parts are written when the writer is disposed. Text is written in the cells (inline strings), so no table of strings grows with the file.

SpreadsheetFormat

Connects spreadsheets to Load(string): after Register(), XLSX and CSV files load as documents, one section per visible sheet with its table of displayed values, so that HTML, Markdown, DOCX, text and RAG chunks work on them. ToDocument() does the same for a workbook already in hand.

TableImportOptions

How FromTables(Document, TableImportOptions?) reads tables' text into cells.

Workbook

The bridge between workbooks, documents and tables.

WorkbookLoadOptions

How a workbook is loaded.

WorkbookSaveOptions

How a workbook is saved.

Worksheet

One sheet of a workbook: up to 1,048,576 rows by 16,384 columns of cells, stored only where cells hold a value or a style. Reach a cell by its A1 address, sheet["B4"], or by zero-based row and column, sheet.Cells[3, 1], and a rectangle of cells with sheet.Range("A1:D20").

WorksheetCells

A sheet's cells: any cell by zero-based row and column, and, when enumerated, the cells that hold a value, a formula or a style, row by row and left to right.

WorksheetCollection

A workbook's worksheets in tab order; names are unique, case ignored, as in Excel.

Structs

CellAddress

Where a cell is on a sheet: a zero-based row and column, written in A1 style as Excel shows it (B4 is row 3, column 1). Rows go up to 1,048,575 and columns up to 16,383 (XFD), the size of an Excel sheet.

CellBorder

One edge of a cell's borders.

CellColor

A colour as spreadsheets give it: automatic, a fixed ARGB colour, a theme colour with a tint, or a legacy palette index. The default value is automatic.

CellRange

A rectangle of cells on a sheet, such as sheet.Range("A1:D20"): a cheap value that reads and writes the sheet's cells. Enumerating it gives every cell in it, empty ones too, row by row; UsedCells gives only the cells that hold something.

CellValue

A cell's value: empty, a number, text, TRUE or FALSE, or an error. Numbers, text, booleans and errors convert to it implicitly, so cell.Value = 42 and cell.Value = "Total" work.

DrawingPosition

A place on a sheet: a cell's top-left corner and an offset from it in EMUs (914,400 an inch, 9,525 a pixel at 96 dpi).

RangeAddress

A rectangle of cells on a sheet, from its top-left cell to its bottom-right cell, written in A1 style as A1:D20. A single cell is written as B4, whole columns as A:C and whole rows as 2:5.
