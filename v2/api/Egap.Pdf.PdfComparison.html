What changed between two documents (Phase 7 design Q12 and Q13): text changes found by a word-level diff over the whole documents, so text that only moved to another page is no change; how pages match; and where matching pages render differently. WriteMarkup(string) writes a copy of the new document with the changes marked.

WriteMarkup(string)

Writes a copy of the new document with the changes marked (Phase 7 design Q13), as Acrobat's Compare does: highlights over inserted, replaced and moved words, the old text in their pop-up notes, carets where words were deleted, and rectangles around areas that only render differently. The new document is not changed.
