Class ChartData

Namespace
Egap.Documents.Charts

One set of a chart's values: a reference to cells, such as Sheet1!$B$2:$B$5, and the values the file keeps for it, which is what a chart draws from when the cells are not at hand. Values are read from the file each time, so hold on to a list you read more than once.
