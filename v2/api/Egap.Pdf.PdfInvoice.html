A Factur-X or ZUGFeRD e-invoice in a PDF: the invoice's XML (UN/CEFACT Cross Industry Invoice) attached to a PDF/A-3 document, with the Factur-X schema in the document's XMP saying the file name, the profile and the version. The XML is the invoicing system's to write; Egap embeds it and reads it back.

Methods

Embed(PdfDocument, ReadOnlySpan<byte>, PdfInvoiceOptions?)

Embeds an invoice's XML: attached under its Factur-X name with the relationship Factur-X asks for and the text/xml type, listed among the document's associated files, the document converted to PDF/A-3 when it is not already, and the Factur-X extension schema written into its XMP. Save the document afterwards.

public static PdfAReport Embed(PdfDocument document, ReadOnlySpan<byte> xml, PdfInvoiceOptions? options = null)

Returns

PdfAReport

The PDF/A conversion's report; it changed nothing when Succeeded is false.

Examples

using PdfDocument pdf = PdfDocument.Open("invoice.pdf");
PdfInvoice.Embed(pdf, File.ReadAllBytes("factur-x.xml"), new PdfInvoiceOptions { Profile = PdfInvoiceProfile.EN16931 });
pdf.Save("invoice-facturx.pdf");

ArgumentException
