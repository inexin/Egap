Whether a save may break signatures knowingly (Phase 5 design Q7). Left false, a save that would invalidate a signature (a change its permissions forbid, or a rewrite of a signed file) adds a SignatureInvalidated warning first, or throws in strict mode.

Encryption

KeepObjectNumbers

For a rewrite, whether objects keep their numbers and generations instead of being renumbered densely in the order they are reached from the trailer. Useful for comparing with the original while debugging. The default is false.

public bool KeepObjectNumbers { get; init; }

Property Value

bool

Linearize

Whether the file is written linearized for fast web view (ISO 32000-1 Annex F, Phase 5 design Q15): a full rewrite with the first page's objects first and hint tables a viewer reads to show pages before the whole file arrives, checked against qpdf. Objects are written on their own with classic cross-reference tables whatever Compression says, and linearization is not combined with encryption. The default is false.

public bool Linearize { get; init; }

Property Value

bool

MergeIdenticalObjects

For a rewrite with Compact, whether identical objects are written once (Phase 2 Q4): streams with the same dictionary and data, and dictionaries and arrays with the same content, such as the logo and fonts of many merged files. The default is true; false saves the time and memory of comparing them, about a tenth of a compact rewrite of a large file with nothing to merge.

public bool MergeIdenticalObjects { get; init; }

Property Value

bool

Mode
