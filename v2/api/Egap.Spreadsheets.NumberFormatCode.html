Class NumberFormatCode

Namespace
Egap.Spreadsheets
Assembly
Egap.Spreadsheets.dll

An Excel number format code, parsed: up to four sections (positive, negative, zero, text) with colours, conditions, digit placeholders, thousands separators and scaling, percent, scientific notation, fractions, dates and times, elapsed times, text and literal characters, and locale tags such as [$-414]. Format(CellValue, CultureInfo?, bool) shows a value as Excel shows it in a cell, for a given culture; Text uses it.

Methods

Format(CellValue, CultureInfo?, bool)

The value as Excel shows it with this format: numbers through the section that applies, text through the text section, TRUE and FALSE, and errors as their text. Separators, month and day names and AM and PM come from culture (the invariant culture, which matches Excel in English, when null), or from the locale tag a section gives. A date before the start of the date system shows as # signs, as Excel shows it.

public string Format(CellValue value, CultureInfo? culture = null, bool date1904 = false)
