The operations of a content stream (8.2): a page's content, a form XObject's, a Type 3 glyph's, or content built from scratch. It is a plain list (Phase 3 design Q3): operations can be read, inserted, removed and replaced, and operators the spec does not define are kept, so content round-trips whatever it holds.

Remarks

A page's content may be several streams (/Contents as an array); they are read as one sequence, since a token may run from one into the next. The list remembers which operations came from which stream, so writing it back rewrites only the streams whose operations changed (Phase 3 design Q4).
