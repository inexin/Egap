Namespace Egap.Documents.Charts

Classes

Chart

A chart, as Excel, Word and PowerPoint keep one in its own part: a DrawingML chart (c:) or one of the newer types (cx:). You can read, change and write what the properties name; everything else in the part stays as the file had it, and a chart you did not change is saved byte for byte. Charts come from a workbook's drawings, from a Word document's islands, or from Create(ChartType, bool).

ChartAxis

An axis of a chart.

ChartBinning

How a histogram or Pareto chart groups its values into bins.

ChartColor

A colour in a chart: fixed or from the theme, with the changes DrawingML applies to it, in order.

ChartData

One set of a chart's values: a reference to cells, such as Sheet1!$B$2:$B$5, and the values the file keeps for it, which is what a chart draws from when the cells are not at hand. Values are read from the file each time, so hold on to a list you read more than once.

ChartDataLabels

What is shown as data labels, for a series, one point or a whole plot.

ChartDrawOptions

ChartFormat

The fill and outline of a chart element. What this does not name, such as shadows, stays as the file had it.

ChartLayout

Where an element sits when placed by hand, as fractions of the chart. Null values leave it to the chart.

ChartLegend

A chart's legend.

ChartMarker

A series's or point's marker.

ChartPlot

One group of series drawn the same way against the same axes. A plain chart has one plot; a combination chart has more. Properties a type does not use read as null. On a cx: chart only the series, axes and gap width apply; setting the rest does nothing.

ChartPoint
