How a workbook calculates: when, whether circular references iterate, and whether chains of formulas may be calculated in parallel. These are the workbook's own settings, saved with it (the calcPr element, ECMA-376 Part 1, 18.2.2).

Concurrent

Whether a full calculation may calculate independent chains of formulas in parallel, the default.

public bool Concurrent { get; set; }

Property Value

bool

FullPrecision

Whether results keep full precision, the default. When false, Excel's "precision as displayed" is on: a value is rounded to the number format of its cell. Kept and saved; the calculation does not apply it yet.

public bool FullPrecision { get; set; }

Property Value

bool

Iterate

Whether formulas in a circular reference are calculated over and over, up to MaxIterations times or until no value changes by more than MaxChange. When false, the default, a circular reference is reported and its cells keep the values they had.

public bool Iterate { get; set; }

Property Value

bool

MaxChange

The change under which iteration stops: once no value in the circular reference moves by more than this, it has settled. 0.001 by default.

public double MaxChange { get; set; }

Property Value

double

Exceptions

ArgumentOutOfRangeException

The change is negative, not a number or infinite.

MaxIterations

The most times a circular reference is calculated when Iterate is on: 1 to 32,767, 100 by default.

public int MaxIterations { get; set; }
