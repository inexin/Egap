Class PdfStructureElement

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

An element of the structure tree (ISO 32000-1 14.7.2, Phase 5 design Q14): its type, the text properties assistive technology reads (title, language, alternate, actual and expanded text), attributes and classes, and its children. Changes are written to the element's dictionary at once; the parent tree is rebuilt when the document is saved.
