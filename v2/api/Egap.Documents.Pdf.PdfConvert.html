Methods

FromFile(string, PdfConvertOptions?)

Makes a PDF of a file: DOCX (and DOTX, DOCM), HTML, Markdown and any other format Load(string) reads are laid out; an image file (JPEG, PNG, TIFF, WebP, GIF and the other formats Egami reads) becomes one page per frame. HTML and Markdown read their images from the file's own folder. HTML needs the Egap.Documents.Html package and HtmlFormat.Register(), Markdown the Egap.Documents.Markdown package and MarkdownFormat.Register().
