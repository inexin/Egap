Egap.Pdf.dll

What Run(PdfDocument, PdfPrintProfile?, CancellationToken) found: every colour space, profile, spot ink, output intent, image resolution, font, transparency, overprint and hairline the document uses, page by page, and the issues that break the print profile it was checked against. Issues are PdfAIssues, as for PDF/A; preflight fixes nothing, so none is fixable.
