Class PdfMetadata

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

The document's metadata (14.3) through one API over both stores (Phase 2 Q8): the document information dictionary (/Info in the trailer) and the XMP packet (the catalog's /Metadata stream). Reading prefers XMP when the packet has the property, as pdf.js does. Setting writes the Info entry and, when the document has an XMP packet or is PDF 2.0, the matching XMP property; a document before 2.0 without a packet gets none unless CreateXmp() is called. Setting null removes the property from both.
