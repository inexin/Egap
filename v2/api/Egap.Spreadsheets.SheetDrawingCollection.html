AddChart(ChartType, RangeAddress, RangeAddress, bool)

Adds a chart of the cells of data, with a series to each column. A first row of text gives the names; the first columns, while they hold text, give the categories, and a scatter or bubble chart takes its X values from the first column whatever it holds. A bubble chart reads its columns in threes: X, Y and size.

AddSlicer(PivotTable, string, RangeAddress)

Adds a slicer of a pivot table's field that fills a range of cells and moves with them: buttons for the field's items, all selected, which filter the pivot table. The slicer is named after the field, and the pivot table is refreshed so the field lists its items; see Slicer to select items and connect other pivot tables.

public SheetDrawing AddSlicer(PivotTable pivotTable, string field, RangeAddress cells)
