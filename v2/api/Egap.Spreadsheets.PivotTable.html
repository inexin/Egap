Remarks

Egap reads pivot tables from .xlsx files and keeps them when it saves one; it does not make new ones. A refresh works out sums, counts, averages, maxima, minima, products, counts of numbers, standard deviations and variances with subtotals and grand totals in the compact, outline, tabular and classic layouts, with page fields, hidden items and sorted fields. A table that shows values as a share or difference, has calculated fields or items, groups items or reads another workbook or a cube cannot be refreshed: see CanRefresh.

Methods

Refresh()

Reads the pivot table's source again and lays out every pivot table that shares its cache, as Excel's Refresh does: new values become new items, the values the source no longer has stay as missing items, and the tables' cells are written again from their top left cells. Formulas in the source give the values they last calculated.

Exceptions

InvalidOperationException

The pivot table cannot be refreshed (see CanRefresh), its source cannot be found or no longer has the cache's fields as its header row, or a table would grow over another pivot table or off the sheet. Nothing changes.
