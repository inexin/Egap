A PDF stream: a dictionary followed by data. A stream is always an indirect object. Its data stays in the file until it is asked for, and an unchanged stream is copied raw when the file is saved.

[SuppressMessage("Naming", "CA1711", Justification = "Named after the PDF object type (design Q1).")]
