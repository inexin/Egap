Class PdfPrintProfile

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

What a print job accepts, as Run(PdfDocument, PdfPrintProfile?, CancellationToken) checks it: the most ink, the least image resolution, the colour spaces allowed, the bleed past the trim box, the thinnest rule and whether fonts must be embedded. A preset fills in the values for a common job; each can be changed with with. A value left null is not checked.
