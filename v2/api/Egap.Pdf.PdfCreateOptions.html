Conformance

The PDF/A conformance the new document claims (Phase 5 design Q11). With one, the document gets the part's PDF version, an sRGB output intent and the XMP identification, and each save writes it by the part's rules: no encryption, a file identifier, no LZW, every font embedded (the standard 14 as metric-compatible substitutes), annotations printed, and for PDF/A-1 no object or cross-reference streams and no transparency. A rule a save cannot meet throws a PdfException naming it. The default is None.

UniversalAccessibility

Whether the new document claims PDF/UA-1 (ISO 14289-1, Phase 5 design Q14): its XMP identifies it, viewers show its title, and each save checks the basics, throwing a PdfException for one it cannot meet: a title and a language, every piece of content tagged or marked as an artifact (BeginTag(PdfStructureElement)), figures with alternate text, annotations tagged, fonts embedded. The default is false.
