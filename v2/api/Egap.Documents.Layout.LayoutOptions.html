Hyphenation

The hyphenation dictionaries automatic hyphenation looks words up in, by each run's language; Egami.Fonts.Layout.HyphenationDictionaries.BuiltIn by default. Words are hyphenated only where the document asks for it (AutoHyphenation, and not in paragraphs with SuppressAutoHyphens), with its limit of lines in a row, hyphenation zone and capitals setting. Text in a language without a dictionary is not hyphenated, and a LayoutWarning of kind HyphenationDictionaryMissing names the language. Null hyphenates only at optional hyphens (U+00AD) in the text.

LineFill

How paragraphs are broken into lines: Egami.Fonts.Layout.LineFill.Greedy (the default) fills each line as far as it goes, as Word does; Egami.Fonts.Layout.LineFill.Optimal chooses the breaks that suit the whole paragraph best, as TeX does, for more even spacing in justified text at some cost in speed, and with lines that differ from Word's. Egami.Fonts.Layout.LineFill.Balanced evens out the lines of paragraphs of up to 6 lines, such as headings.

Strict

Whether layout fails loudly instead of degrading: a LayoutException naming the node is thrown when text runs past its column or an object, table row or paragraph past its page area, when a character has no glyph in any font, or when a font the document names has no stand-in but the last resort. Off by default, so converting someone else's file never fails on its content.
