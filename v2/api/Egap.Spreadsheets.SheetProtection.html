Class SheetProtection

Namespace

A sheet's protection, as Excel's Protect Sheet sets it: whether it is on, what users may still do, the hash of the password that lifts it, and the ranges that stay editable. Locked cells (Locked, the default) cannot be changed while it is on, and the formulas of hidden cells (Hidden) are not shown.

Examples

sheet.Range("B2:B10").UpdateStyle(s => s with { Protection = s.Protection with { Locked = false } });
sheet.Protection.Protect("secret", SheetActions.Default | SheetActions.Sort);
bool open = sheet.Protection.Unprotect("secret");    // true

Remarks

Egap does not enforce protection: it reads, writes and checks it, so that Excel enforces it. Protection is not encryption, and anyone with the file can read every cell. Protect(string?, SheetActions) stores a SHA-512 hash of the password with a random salt and 100,000 spins, as Excel does; Verify(string?) also checks the 16-bit hashes of older files.
