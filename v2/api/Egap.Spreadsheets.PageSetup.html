How a sheet prints: paper, orientation, scaling, margins, centring, gridlines, headings, page order, the header and footer, the print area, the rows and columns repeated on each page and the manual page breaks. The print area and the titles are kept as Excel keeps them, as the sheet's defined names _xlnm.Print_Area and _xlnm.Print_Titles in Names.
