Class PdfSignature

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

A signature or document timestamp in a signed signature field (ISO 32000-2, 12.8): its value dictionary, the bytes it signs and the revision those bytes are. Reading checks nothing cryptographic; ByteRangeIssues reports what is wrong with the byte range itself.

Examples

foreach (PdfSignature signature in pdf.Signatures)
{
    Console.WriteLine($"{signature.Name}: {signature.Kind} {signature.SubFilter}, revision {signature.Revision?.Index}");
    if (signature.ByteRangeIssues != PdfByteRangeIssues.None) Console.WriteLine($"  byte range: {signature.ByteRangeIssues}");
}
