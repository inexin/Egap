Class PdfXConverter

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

Checks documents against PDF/X and converts them to it (Phase 8 design Q9, Q10). PDF/X-4 and X-6 are checked and converted; X-1a and X-3 too when the file has no transparency, which conversion does not flatten; X-4p, X-5g, X-5pg and X-6p are checked only; X-5n and X-6n are checked, with an n-colorant output intent. Conversion fixes in place what it can (output intent, trim and bleed boxes, identification and metadata, trapping key, fonts, colours through PdfColorConverter, transfer functions, annotations in the print area, actions) and reports every fix; when a rule cannot be met nothing is changed. Issues are PdfAIssues, as for PDF/A. No open validator judges PDF/X: Acrobat Preflight or PackzView is the full judge.

Examples

using PdfDocument pdf = PdfDocument.Open("brochure.pdf");
PdfAReport report = PdfXConverter.Convert(pdf, PdfXConformance.PdfX4, new PdfXConvertOptions { OutputCondition = PdfOutputCondition.Fogra39, Bleed = 3 });
if (report.Succeeded)
{
    pdf.Save("print.pdf");
}
