A table in a GraphicFrame (a:tbl): its grid of columns and rows, the cells' text and how cells are merged. Cell, row and table formatting the model does not hold (borders, fills, margins) are kept as they are. A row, column or cell object stays valid until a row or column is added or removed; read them again from the table then.
