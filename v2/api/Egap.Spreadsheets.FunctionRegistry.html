Class FunctionRegistry

Namespace
Egap.Spreadsheets

The worksheet functions formulas can call: the built-in ones, and functions you add for your own formulas, as a user-defined function in Excel. A function you add is known to every workbook in the process from then on; formulas read it when they are next calculated or evaluated.

Methods

Add(string, int, int, Func<IReadOnlyList<FunctionArgument>, CellValue>)

Adds a function, or replaces one added before under the same name. Its arguments come as given: a range stays a range, and its Values are the cells. An exception the function throws gives #VALUE! in the cell, as an error in a user-defined function does in Excel.

public static void Add(string name, int minArguments, int maxArguments, Func<IReadOnlyList<FunctionArgument>, CellValue> function)

Parameters

name string

The function's name, without case: letters, digits, . and , starting with a letter or .

minArguments int

The fewest arguments a call may give, 0 to 255.

maxArguments int

The most arguments a call may give, minArguments to 255; a call outside gives #VALUE!.

function Func<IReadOnlyList<FunctionArgument>, CellValue>

The function's code: given the arguments, gives the value.

Exceptions

ArgumentNullException

ArgumentException

ArgumentOutOfRangeException
