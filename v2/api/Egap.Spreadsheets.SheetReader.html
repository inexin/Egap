Class SheetReader

Namespace
Egap.Spreadsheets
Assembly
Egap.Spreadsheets.dll

Reads a sheet's rows one at a time from an XLSX file or CSV text, without building a Workbook: memory stays the same however many rows there are. An XLSX file's shared strings and styles are read first, as every cell may use them; the rows are then read from the sheet's part as they come.
