Namespace Egap.Documents.Reports

Classes

ColumnBuilder

Elements one under another.

Container

A place in a report that takes one element (text, an image, a column, a row, a table, a grid, a barcode, a form field or a component), with the box, alignment, style and paging settings set on it first: each setting returns the container, and the element ends the chain.

GridBuilder

Elements in a grid of tracks.

PageDescriptor

One page of a report, repeated as the content needs: size, margins, header, footer and content.

Report

Builds a document from code with nested lambdas: pages with a header, a footer and content, and in them columns, rows, tables, grids, text, images and barcodes, each with its box and paging settings. The result is an ordinary Document, so the same report saves as PDF, DOCX or HTML and lays out with the same page flow.

ReportBuilder

What Create(Action<ReportBuilder>, LayoutOptions?) gives the composing code: the document's properties, styles and pages.

RowBuilder

Elements side by side: each of a fixed width, its content's width, or a share of what is left.

TableBuilder

A table: columns, cells filled in order row by row, and header and footer rows that repeat on every page.

TableColumns

The columns of a table: fixed widths and shares of what is left.

TextBuilder

The spans of one paragraph, each with its own style.

TextDescriptor

A paragraph of text a container made: its look set by a style chain.

TextStyle

How text in a report looks: font, size, weight, slant, lines, colours, letter spacing and line height. Immutable: each method returns a changed copy, so a style can be kept and shared (TextStyle.Default.FontSize(18).Bold()). What a style leaves unset comes from the style of the text around it.

Interfaces

IComponent

A reusable part of a report: it composes itself into the container it is given.
