Class PdfStructureTree

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

A document's logical structure (ISO 32000-1 14.7, Phase 5 design Q14): the tree of structure elements, the role map from the document's own types to standard ones, and the class map of shared attributes. Elements are read from and written to the file's objects directly; the parent tree that leads from page content back to elements is rebuilt from the elements when the document is saved after a change. Page import and merge bring the elements of the pages they copy.
