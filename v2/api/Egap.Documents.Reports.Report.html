Class Report

Namespace
Egap.Documents.Reports
Assembly
Egap.Documents.dll

Builds a document from code with nested lambdas: pages with a header, a footer and content, and in them columns, rows, tables, grids, text, images and barcodes, each with its box and paging settings. The result is an ordinary Document, so the same report saves as PDF, DOCX or HTML and lays out with the same page flow.

Examples

Document invoice = Report.Create(r => r.Page(p => p
    .Size(PdfPageSize.A4).Margins(Length.Mm(15))
    .Header(h => h.Row(row =>
    {
        row.Grow().Text("Acme Ltd").FontSize(20).Bold();
        row.Auto().AlignRight().Text("Invoice 2026-118");
    }))
    .Content(c => c.Column(col =>
    {
        col.Spacing(6);
        col.Item().Text("Thank you for your order.");
        col.Item().Table(t => t.Columns(3).Header("Item", "Qty", "Price").Rows(lines, l => [l.Name, l.Qty, l.Price]));
    }))
    .Footer(f => f.AlignCenter().Text($"Page {Fields.Page} of {Fields.Pages}"))));
invoice.SaveAsPdf("invoice.pdf");

Create(Action<ReportBuilder>, LayoutOptions?)

A new document built by compose. Its layout is strict and uses only portable fonts unless layout says otherwise (DefaultLayoutOptions), so a report that does not fit fails loudly and prints the same on every machine.
