Class MarkdownFormat

Namespace
Egap.Documents
Assembly
Egap.Documents.Markdown.dll

Reads Markdown into a Document and writes documents as GitHub Flavored Markdown: CommonMark 0.31 with GitHub's tables, task lists, strikethrough, autolinks and footnotes, and YAML front matter, parsed by Markdig. Headings take the Heading 1 to 6 styles, code the HTML Code and HTML Preformatted styles, lists Word list definitions built from their nesting. Writing says in warnings what Markdown cannot hold.
