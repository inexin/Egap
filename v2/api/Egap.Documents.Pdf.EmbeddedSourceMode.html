When PdfToDocument uses a DOCX copy of the document that a hybrid PDF carries.

public enum EmbeddedSourceMode

Fields

Ignore = 1

The pages are always analysed; a copy is left alone.

Prefer = 0

The default: the copy is used when it can be trusted (marked as the source, a DOCX, written by Egap and not followed by any later change to the PDF); otherwise the pages are analysed, with a warning saying why the copy was not used.

Require = 2

The copy must be used: a PDF without a trusted one throws.
