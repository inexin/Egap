Enum PdfXConformance

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

A PDF/X version a file is checked against or converted to (ISO 15930; Phase 8 design Q9).

public enum PdfXConformance

Fields

None = 0

No PDF/X claim.

PdfX1a = 1

PDF/X-1a:2003 (ISO 15930-4, PDF 1.4): CMYK, gray and spot colours only, no transparency, everything embedded.

PdfX3 = 2

PDF/X-3:2003 (ISO 15930-6, PDF 1.4): PDF/X-1a with colour-managed (ICC, calibrated, Lab) colours allowed.

PdfX4 = 3

PDF/X-4 (ISO 15930-7, PDF 1.6): colour-managed colours, live transparency and optional content.

PdfX4p = 4

PDF/X-4p: PDF/X-4 whose output intent profile is referenced, not embedded. Checked only.

PdfX5g = 5

PDF/X-5g (ISO 15930-8): PDF/X-4 that may reference external graphical content. Checked only.

PdfX5n = 7

PDF/X-5n: PDF/X-4 printed with an n-colorant characterization (more than CMYK).

PdfX5pg = 6

PDF/X-5pg: PDF/X-5g with a referenced output intent profile. Checked only.

PdfX6 = 8

PDF/X-6 (ISO 15930-9, PDF 2.0): PDF/X-4's rules on PDF 2.0.

PdfX6n = 10

PDF/X-6n: PDF/X-6 printed with an n-colorant characterization.

PdfX6p = 9

PDF/X-6p: PDF/X-6 with a referenced output intent profile. Checked only.
