The filter of a sheet or table, as a file holds it: its range and the criteria of its columns. Apply() hides the rows that fail the criteria, as Excel's Reapply does; Excel itself only hides rows when a filter is set or reapplied, and keeps them as they are when it opens a file.

Methods

Apply()

Shows the data rows that meet every column's criteria and hides the rest, as Excel's Reapply does. Values in a list match the text a cell shows, without case; custom criteria compare numbers with numbers and text with text, and their wildcards match text only; top and bottom items and above or below average take the column's numbers; date periods count from today. Colour and icon criteria are not evaluated: a row passes them.

public int Apply()

int

How many data rows show.

Remarks

Formulas filter by their last results, so calculate the workbook first when they have changed.

ShowAll()

Clears every column's criteria and shows the filter's data rows, as Excel's Clear does; the filter and its buttons stay.
