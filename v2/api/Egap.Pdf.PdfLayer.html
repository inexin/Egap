An optional content group (8.11.2), a layer: a thin view over its dictionary. Its visibility and lock are read from and written to the document's default configuration (/OCProperties /D). Two views are equal when they wrap the same dictionary.

RemoveContent()

Removes what the layer shows from every page and every form XObject the pages draw: content marked with the layer (/OC … BDC to EMC) and XObjects whose /OC names it, membership dictionaries that depend on it included (content shown with the layer on and hidden with it off). With the layer then hidden, the pages render as they did with it hidden before; content shown only while the layer is off (a membership dictionary with /Not) is kept. The layer itself stays; remove it with Remove(PdfLayer, bool).

public int RemoveContent()

Returns

int

How many marked sequences and XObject draws were removed.

Remarks

Hidden content still sets the graphics state, so a sequence whose state changes outlive it keeps them: its painting is taken out instead. Only page content streams that change are rewritten (Phase 3 design Q4).
