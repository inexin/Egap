Add(CellAddress, string, PivotTableOptions, string?)

Makes a pivot table of a source range, an Excel table or a defined name, and lays it out from the source's values as Excel does when it makes one. The table's top left cell is location, or, with filters, the filters start there and the table starts a row under the last of them. The cells it takes are written over.

public PivotTable Add(CellAddress location, string source, PivotTableOptions options, string? name = null)

Parameters

location CellAddress

Where the pivot table goes.

source string

The source with its header row: a range such as Data!A1:G61 or A1:G61 on this sheet, the name of an Excel table, or a defined name of one range. Each column is a field, named by its header cell.

options PivotTableOptions

The fields on rows, columns and filters, the values and how the table looks.

name string

The pivot table's name, or null for the next free PivotTableN.

Returns

PivotTable

Exceptions

ArgumentException

The source is not a range, table or name of the workbook, a header cell is empty, the options name a field the source lacks or put one on two axes, or the name is taken on the sheet.

InvalidOperationException

The table would overlap another pivot table or go off the sheet.
