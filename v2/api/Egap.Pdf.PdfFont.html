Class PdfFont

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

A font a page's text uses (Phase 3 design Q7): read-only. It says what kind of font it is, its names, flags and metrics, how its strings split into codes, each code's width and glyph name, and the text a code stands for, through the font's ToUnicode map first, then its encoding's glyph names through the Adobe Glyph List. Fonts are read leniently: what a file gets wrong gives no answer rather than an exception.
