Class SlideShape

Namespace
Egap.Presentations

A shape on a slide, layout or master: an AutoShape, PictureShape, GroupShape, ConnectorShape or GraphicFrame. Its id, name and position are read from the file and written back where they change; everything else the shape holds is kept as it was.

InheritedPlaceholder

The placeholder this one takes what it does not set itself from: for a slide's placeholder, its layout's; for a layout's, its master's; null for a master's, a notes page's without a master, or a shape that is not a placeholder. A slide's placeholder is matched by index first and then by type; a layout's or notes page's by type, a centred title taking the master's title and the content kinds (subtitle, content, chart, table, picture and the rest) its body.
