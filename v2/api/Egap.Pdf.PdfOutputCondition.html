A registered print characterization (design Q10): the identifier PDF/X output intents name, such as FOGRA39, how it is described, and the ICC profile that is embedded with it. Fogra39 carries Egami's bundled profile; the others need one from the caller (WithProfile(ColorProfile)), since their profiles may not be redistributed freely.
