A slicer: buttons for the items of a pivot table field, which filter the pivot tables it is connected to. Selecting items hides the others in those tables and refreshes them, as clicking the slicer in Excel does. A slicer sits on a sheet's drawing layer: see AddSlicer(PivotTable, string, RangeAddress) and Slicer.

Remarks

Egap reads the slicers of pivot tables from .xlsx files, keeps them when it saves, draws them when it prints and makes new ones. Slicers of Excel tables and of cubes are kept and drawn as the file left them, but cannot be changed.
