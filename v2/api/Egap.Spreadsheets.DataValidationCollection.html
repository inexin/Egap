IsValid(CellAddress, CellValue)

Whether a value would pass the rule that applies to a cell, were it entered there, as Excel checks a value typed in; true when no rule applies. Numbers, dates and times pass by comparison with the rule's formulas, a whole number only when it has no fraction; a logical compares above every number, as in Excel; text and errors fail them. A list rule's fixed items match with case, its cells' values without. Text length counts the value as text. An empty value passes when the rule allows blanks.
