Identify(Stream, string?)

Tells which format a file is in without loading it, from its first bytes and, for text, its extension: a ZIP package or an old compound file is Word's, %PDF- is PDF, a JSON object naming the DoclingDocument schema is Docling JSON, text that starts with a tag is HTML, and other text is Markdown, or plain text when the extension says so. It needs no add-on package, so a program can tell its user which package a file needs.

public static DocumentFormatKind Identify(Stream stream, string? fileName = null)
