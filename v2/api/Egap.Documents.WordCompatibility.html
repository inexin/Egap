Class WordCompatibility

Namespace

Word's compatibility options that change how Egap lays a document out, one named flag each (Word's w:compat settings). A flag's value is the one the file or code set, else the default for the document's CompatibilityMode, so changing the mode changes every flag nobody set. Word's other compatibility options are read too, kept for round trips and listed in OtherSettings.

Remarks

A new document has Word 2013's settings: OverrideTableStyleFontSizeAndJustification and EnableOpenTypeFeatures on, and Word's doNotFlipMirrorIndents and differentiateMultirowTableHeaders in OtherSettings. A DOCX file's flags are what its settings part says; a flag the file does not set is off, as ECMA-376 and Word's own extensions define it.

OverrideTableStyleFontSizeAndJustification

A table style's font size and alignment win over the default paragraph style's, as the style hierarchy says.
