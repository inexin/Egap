Namespace Egap.Pdf.Ocr

Classes

PdfOcr

Makes scanned PDFs searchable through any OCR engine (an Egami.Ocr.IOcrEngine from Egami.Ocr): each page's image goes to the engine, and the words that come back are written over the page as invisible text, placed and scaled so selection follows the scan. Egap ships no engine; plug in Egami.Ocr.CommandOcrEngine for a program such as Tesseract, or your own class around an OS or cloud service.
