Save(string, PresentationSaveOptions?)

Saves the presentation to a file as the kind its extension names (.pptx, .pptm, .potx, .potm, .ppsx or .ppsm), unless Format names one. A deck with macros saved as a kind without them leaves the macros out. With Password, the file is encrypted (agile encryption, as PowerPoint 2010 and later write it).

Sets the password to modify the file, which PowerPoint asks for before it lets anyone edit (it opens the file read-only otherwise), or removes it with null. The password is kept as a salted SHA-512 hash, as PowerPoint 2013 and later write it.
