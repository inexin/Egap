Struct Length

Namespace
Egap.Pdf

Egap.Pdf.dll

A length on the page, held in points (1/72 inch) and made from points, millimetres, centimetres or inches, so sizes in different units cannot be mixed up. It converts to and from a double in points without a cast, so it can be passed wherever a size in points is asked for, and a plain number still works wherever a Length is.
