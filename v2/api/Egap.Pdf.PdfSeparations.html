Class PdfSeparations

Namespace
Egap.Pdf
Assembly
Egap.Pdf.dll

A page rendered as ink plates (Phase 8 design Q4, Q5): one gray raster per process and spot ink, drawn by a true multi-ink renderer, so overprint, knockout and blend modes act on the inks as a press prints them. It measures total area coverage (TAC), the sum of every plate in percent, and draws a heat map of it. Dispose it to free the plates.

Examples

using PdfSeparations plates = pdf.Pages[0].RenderSeparations(new PdfRenderOptions { Dpi = 150 });
foreach (PdfInkPlate plate in plates.Plates)
{
    plate.Raster.Save($"{plate.Name}.png");
}

Console.WriteLine($"max TAC {plates.MaxCoverage:0}%, {plates.ShareOver(300):P1} of the page over 300%");
