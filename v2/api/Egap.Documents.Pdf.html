LayoutTable

A table: its cells on a grid of RowCount by ColumnCount. A table from a tagged PDF keeps the tags' cells and their order, with spans taken from the page's rules or text where the tags give none (as Word's do not).

LayoutTableCell

A table cell.

LayoutThresholds

Every threshold the geometric stages use (design Q1: every threshold an option). Distances are in multiples of the text size unless they say otherwise, so they hold for any font size. The defaults are tuned against the comparison data sets and may change in a minor version; the properties themselves stay.

LayoutWord

A word with the font it is mostly set in.

PageBand

A header or footer that PdfConvert puts on every page (Header and Footer), in the top or bottom margin: plain text in up to three places (Text(string?, string?, string?)), or HTML styled with the page's own CSS (Html(string)). Both take the PdfPlaceholders: {page}, {total-pages}, {label}, {date}, {time}, {title} and {file}.

PdfAutoTagFigure

A figure tagged without alternate text.

PdfAutoTagReport

What Tag(PdfDocument, PdfLayoutOptions?, CancellationToken) did.

PdfAutoTagger

Tags an untagged PDF from its layout (design Q11, Build Plan task 14): a structure tree through Phase 5's model, with headings, paragraphs, lists, tables, figures, captions, quotes, code and notes in reading order, page headers and footers and decoration marked as artifacts, and the page content wrapped in marked content that points at its element. Figures get no alternate text: the report lists them, and writing it stays with the caller.

PdfConvert

One-line conversions to PDF: HTML, Markdown, DOCX and images in, a PDF file or an open PdfDocument out. Each reads the input with Egap.Documents, lays it out and exports it as PdfExport does.

PdfConvertOptions

How PdfConvert turns HTML, Markdown, DOCX and images into PDF.

PdfExport

Flow documents saved as PDF (Phase 6 design Q2, Build Plan task 22): each laid-out page drawn on a PdfCanvas, with link annotations for hyperlinks, an outline, named destinations for bookmarks, the document's properties as metadata, and on request tags and PDF/A.

PdfExportOptions

How a flow document is saved as PDF (Phase 6 design Q2, Build Plan task 22).

PdfLayoutAnalyzer

Layout analysis of PDF pages (design Q10, Build Plan task 10): blocks with roles, tables and figures in reading order, without building a document model. Tagged pages whose tags pass a sanity check are read from their tags (design Q2); others by geometric rules (design Q1, Q3 to Q7), every threshold an option and the main stages replaceable through PdfLayoutOptions.

PdfLayoutOptions

How layout analysis runs (design Q2, Q5, Q10): whether tags are trusted, which tables are looked for, the stages a caller replaces, and every threshold.

PdfPageLayout

What layout analysis found on one page (design Q10): text blocks with their roles, tables and figures, each with its bounds and place in the page's reading order. Bounds are in points on the displayed page: y down from the top left of the crop box, the page's rotation applied, as PdfCanvas draws by default.

PdfToDocument

PDF to the flow document model (design Q6 to Q8, Q10): layout analysis, then the pages joined into sections with styles, lists, tables, pictures, headers and footers and footnotes, ready to save as Word, HTML or Markdown through Egap.Documents.

PdfToDocumentOptions

How PdfToDocument analyses a PDF and builds the document.

PdfToDocumentWarning

What PdfToDocument could not carry over as it was, on which page.

TableCsv

Detected tables as CSV (RFC 4180; Build Plan task 19): one CSV per table, a table that runs on across pages written once with its repeated header left out, merged cells repeated across their span or left empty, and the number of header rows given with each so a reader can treat them as headers.

TableCsvFile

A table written as CSV.

TableCsvOptions

How TableCsv writes tables.

PageMargins

Interfaces

ILayoutRegionDetector

Supplies regions and roles for a page from outside Egap's own rules, such as a layout model the caller already runs (design Q1): Egap ships no model, and this is the place one plugs in. A region the detector names takes precedence over what the rules would find there; the rules still group the text inside it into lines and paragraphs.

IReadingOrderDetector

Orders a page's blocks, tables and figures, in place of Egap's XY cut.

ITableDetector

Finds where a page's tables are, in place of Egap's own detection; Egap then finds the cells inside each area.
