Spreadsheet functions

Egap.Spreadsheets has 476 of the 524 functions on Microsoft's list of Excel's functions. Each is checked against what Excel calculates, with the cases in tests/Egap.Spreadsheets.Tests/Oracle/functions*.txt. The tests make this page, and fail when it is out of date: python tools/update-function-coverage.py writes it again.

A file that calls a function not built in keeps the formula and the value saved with it until the cell is calculated, when it gives #NAME?. FunctionRegistry.Add adds one of your own.
