DOCX

Egap.Documents reads and writes Word's files: documents (.docx), templates (.dotx) and their macro-enabled forms (.docm, .dotm), strict and transitional. It needs no add-on package.

Reading

A Word file reads into the model with Word's style model, lists numbered as Word numbers them, tables, fields, comments and tracked changes; the flow documents guide shows what you can do with them. What the model does not name travels along in each node's extension data. Macros are kept and never run. An old binary Word file (.doc) is recognized and refused with an error that says so. DocxLoadOptions.Limits keeps untrusted files in bounds (see Limits).

using Egap.Documents;

Document report = Document.LoadDocx("report.docx", out IReadOnlyList<ConversionWarning> warnings);
DocxKind? kind = DocxFormat.KindOf(report);                       // Document, Template or a macro-enabled kind
report.SaveAsDocx("report-copy.docx");                            // what the model does not name is kept
DocxFormat.Save(report, "report.dotx", new DocxSaveOptions { Kind = DocxKind.Template });

Writing

DOCX to DOCX is lossless: parts and paragraphs you did not edit are written as they were read. Saving to a path takes the kind from the extension, so report.dotx is a template; saving to a stream keeps the kind the document was read as (a new document is a .docx). DocxSaveOptions.Kind overrides both. A kind that holds no macros drops the macros a .docm or .dotm had.

A document read from another format saves as DOCX with what Word can hold. Some things the model has Word does not:

  • Word has no word spacing or overline; it keeps the OpenType features it knows (ligatures, number forms and spacing, stylistic sets, contextual alternates). See Text options.
  • Paging settings on groups of blocks, clamped lines and balanced columns are not saved; the content is. See Page layout.
  • Margin boxes at the top and bottom of the page are saved as a three-part table in the header or footer; those in the corners and at the sides are left out with a warning.
  • Flex and grid containers are saved as borderless tables with their items in the cells, and a group with a box as a one-cell table; the cells keep the items' backgrounds, borders and padding, not rounded corners or shadows. See Flex and grid layout.
  • An SVG picture is saved with the PNG stand-in in Picture.Fallback, as Word stores SVG pictures, so older readers show it too. Barcodes get one at 300 pixels per inch.
