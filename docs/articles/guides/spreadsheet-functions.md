# Spreadsheet functions

Egap.Spreadsheets has 491 of the 524 functions on Microsoft's list of Excel's functions. Each is checked
against what Excel calculates, with the cases in `tests/Egap.Spreadsheets.Tests/Oracle/functions*.txt`. The tests make
this page, and fail when it is out of date: `python tools/update-function-coverage.py` writes it again.

A file that calls a function not built in keeps the formula and the value saved with it until the cell is calculated,
when it gives `#NAME?`. `FunctionRegistry.Add` adds one of your own.

## Not planned yet (33)

They ask a service on the web, which a library that calculates offline has no answer from.

`DETECTLANGUAGE`, `IMAGE`, `STOCKHISTORY`, `TRANSLATE`, `WEBSERVICE`

They ask a data model, which Egap does not load.

`CUBEKPIMEMBER`, `CUBEMEMBER`, `CUBEMEMBERPROPERTY`, `CUBERANKEDMEMBER`, `CUBESET`, `CUBESETCOUNT`,
`CUBEVALUE`

They run code from outside the workbook.

`CALL`, `EUROCONVERT`, `REGISTER.ID`, `RTD`

They work in the bytes of double-byte text or on East Asian text conversions, which need the tables of those code pages.

`ASC`, `DBCS`, `FINDB`, `JIS`, `LEFTB`, `LENB`, `MIDB`, `PHONETIC`, `REPLACEB`, `RIGHTB`, `SEARCHB`

They read a file or a web page as they calculate, which a library should not do for a workbook it opens.

`IMPORTCSV`, `IMPORTTEXT`

Excel does not document how it fits their model's parameters, so Egap leaves them out rather than give other numbers.

`FORECAST.ETS`, `FORECAST.ETS.CONFINT`, `FORECAST.ETS.SEASONALITY`, `FORECAST.ETS.STAT`
